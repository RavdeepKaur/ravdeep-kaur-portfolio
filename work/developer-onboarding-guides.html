Mobile EnablementReact Native Mobile Setup Guide

  1. Verify Node.js, npm, Java/JDK requirements, Android Studio, Android SDK, and emulator configuration.
  2. Create or open the project in VS Code and confirm package dependencies are installed.
  3. Start the Android emulator before running the mobile project.
  4. Run the project with npx react-native run-android or the required project command.
  5. Make a small text or button change and verify the update in the emulator.
  6. Document any build errors with the command used, error message, attempted fix, and final resolution.

Common Troubleshooting Notes

Check SDK path settings, emulator state, Metro bundler status, port conflicts, package installation, and whether the app needs a clean rebuild after dependency changes.

Full-Stack EnablementASP.NET MVC and Database Onboarding Notes

Technical objective: understand application structure, routing, controllers, actions, models, views, connection strings, Entity Framework Core registration, migrations, and database validation. 

// appsettings.json
"MVC_ConnectionString": "Server=(localdb)\\mssqllocaldb;Database=MvcAppDb;Trusted_Connection=True;"

// Program.cs focus:
// register DbContext, confirm dependency injection, then test controller/database flow.
  • Confirm the connection string points to the intended local or development database.
  • Explain where services are registered and how controllers receive dependencies.
  • Run a simple create/read action before adding more complex features.
  • Use error messages to distinguish routing, model, database, and migration issues.

CMS EnablementJoomla Website Build Checklist

  • Install and run XAMPP for local hosting.
  • Place Joomla files in the local server directory and complete setup.
  • Create categories for site pages, blog content, services, and media.
  • Add Home, About, Services, Gallery, Contact, and Blog pages.
  • Configure navigation, banners, footer items, article images, template layout, and database export.
  • Validate the final site by checking links, page titles, images, forms, and mobile layout.
